立即测试步骤：
-------------
1. 访问 /test-auth 页面
   - 查看认证状态
   - 如果显示 authenticated，点击"前往 Dashboard"
   - 观察是否被重定向回登录页

2. 访问 /auth-debug 页面
   - 查看详细的调试信息
   - 检查 cookies 是否包含 sb- 开头的 cookie
   - 检查 session 是否存在
   - 检查 profile 数据

3. 检查浏览器控制台
   - 查看是否有 [AUTH] 开头的日志
   - 查看是否有错误信息

可能的问题原因：
--------------
1. Cookie 域名问题
   - 生产环境 domain 设置为 .familybank.chat
   - 确认线上域名是否正确

2. useSupabaseUser() 在 middleware 中返回 null
   - Nuxt Supabase 模块可能在 middleware 执行时还未初始化
   - 需要使用 getSession() 而不是 useSupabaseUser()

3. PKCE 流程问题
   - callback 处理可能有问题
   - code exchange 可能失败

下一步修复方案：
--------------
如果 /test-auth 显示 authenticated 但访问 /dashboard 还是被重定向：

方案 A：修改 middleware 使用 getSession() 而不是 useSupabaseUser()
方案 B：在 nuxt.config.ts 中禁用自动重定向，手动处理
方案 C：检查 cookie 的 sameSite 和 secure 设置
